# MySQL Source Code Assessment Checklist

An interactive manual checklist for reviewing application code that talks to MySQL.

- 13 sections covering SQL injection, auth, credentials, data protection, error handling, concurrency, dangerous MySQL features, configuration and reporting
- Click any item to see what to check and why it is vulnerable
- Progress is saved in your browser (localStorage)
- Single self-contained HTML file, no dependencies, works offline

## Usage

Open `index.html` in a browser.

To host it with GitHub Pages: Settings > Pages > Deploy from a branch > `main` / root.
